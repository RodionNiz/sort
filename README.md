# OneginSort

Программа читает текстовый файл (например Onegin.txt), и, если он не засекречен гостайной, сортирует его строки в лексикографическом порядке, после в режиме рифмовщика. Последовательно печатает в новый файл два варианта сортировки и оригинальный текст. Если файл засекречен, то включает **VPN**, после чего делает то же самое.

## О проекте

Структурируя строки из текстового файла, проект помогает литераторам и прочим гуммунитариям прикоснуться к совершенству технической части этого мира (или напитаться рифмами для батла).

---

## Принцип работы

- Считывает файл полностью в отдельный буффер.
- Создает массив структур, включающих в себя указатель на начало строки и ее длину.
- Сортирует структуры в выбранном режиме.
- Печатает результат сортировки в отдельный файл.

---

## Сборка

Т.к. внутри файла есть assert (ptr != nullptr) для проверки корректности указателей, то код не может быть скомпилирован компилятором c.
Для корректной компиляции нужно использовать компилятор c++ старше стандарта c++17.

> Можно использовать компилятор C с флагом NDEBUG
---

## Запуск

Программа способна принимать два ключа компиляции - имя файла, который нужно отсортировать; имя файла, в который будет записан результат.

**Пример корректного ввода**:

.\OneginSort.exe Onegin.txt SortedText.txt

> Имена файлов не являются обязательными параметрами. При наличии только одного имени отсортированый текст из файла с указаным именем будет по умолчанию записан в файл с именем SortedText.txt. При отсутствии имен чтение по умолчанию происходит из файла Onegin.txt, запись происходит в файл SortedText.txt.

При указании слишком большого количества аргументов программа будет замершена с кодом ошибки -1.
При указании имени несуществующего файла для чтения программа будет замершена с кодом ошибки -2.

## Структура кода

├── enum ErrsCode содержит иформацию о возможных кодах ошибок
├── enum PrintStrReason содержит возможные режимы работы функции PrintString.
├── struct String Содержит указатель на начало строки и ее длину.
├── struct TextStates Содержит информацию о тексте из читаемого файла: длина, количество строк (пустых и значимых), указатель на начало текста,
├──                   массив структур String с информацией о каждой строке.
├── TextStates ParseText Содержит логику чтения и разбиения оригинального текста.
├── size_t CountFileSize Узнает и возвращает байтовый размер читаемого файла.
├── char* ReadFile Копирует текст в область динамической памяти, возвращает указатель на его начало.
├── size_t CountStrings Считает количество строк в исходном тексте (основывается на разделении символом '\n')
├── size_t FillIndex Заполняет массив структур информацией о содержащихся в исходном тексте строках.
├── void QSort Блок логики копии стандартного qsort
├── size_t Partition Разделение сортируемого массива по опорному элементу (средний элемент).
├── void ByteSwap При сортировки побайтово меняет информацию
├── int CompareDirect Компаратор, сортирующий строки в лексикографическом порядке.
├── int CompareReverse Компаратор, сортирующий строки в порядке рифмовщика.
├── int ComparePtrs Компаратор, сортирующий указатели на структуры в порядке возрастания. Необходим для вывода оригинального текста
├── void PrintStrings Выводит считанный (отсортированый) текст в одном издвух режимах (режим дебага, режим ввывода ответа).
└── void ClearMem Очищает использованную динамическую память.
