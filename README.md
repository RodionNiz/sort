# OneginSort

Программа на C, которая читает текстовый файл, сортирует его строки **двумя способами** — в лексикографическом порядке и в порядке «от конца к началу» (режим рифмовщика), после чего сохраняет все три варианта в один файл: два отсортированных и исходный.

## 📖 О проекте

**Ключевые возможности:**

- ✅ Чтение файла целиком в один буфер (`ReadFile`)
- ✅ Индексация непустых «значащих» строк (`FillIndex`)
- ✅ Собственный `QSort`, аналогичный стандартному (`Partition`, `ByteSwap`)
- ✅ Компаратор `CompareDirect` — обычная сортировка (A → Z)
- ✅ Компаратор `CompareReverse` — сортировка с конца строки (рифмовщик)
- ✅ Вывод оригинала в исходном порядке

---

## ⚙️ Алгоритм работы

1. Файл целиком читается в буфер `text`, находящийся в динамической памяти.
2. В буфере подсчитываются строки и строится массив указателей `textPtrs` на начала **значащих** строк (тех, где есть хотя бы одна буква). Разделители заменяются на `'\0'`.
3. Массив указателей сортируется с помощью аналога стандартной функции быстрой сортировка - **`QSort`**. Используется компаратор `CompareDirect` — обычный алфавитный порядок.
4. Результат пишется в файл.
5. Тот же массив сортируется стандартным **`qsort`** с компаратором `CompareReverse` — сравнение идёт с конца строки (так строки выстраиваются «по рифме»).
6. Результат снова пишется в файл.
7. В конце выводится исходный текст (через обход буфера по `'\0'`).

## 🛠 Сборка

Для компиляции следует использовать компилятор c++ (с++17 и моложе) в связи с наличием проверок на нулевой указатель в формате assert (ptr != nullptr).

Использование стандартных C компиляторов возможно с флагом компиляции **-DNDEBUG**

## 🚀 Использование
При запуске следует указать путь к файлу с сортируемым текстом в качесте аргумента

```bash
./onegin_sort <путь_к_текстовому_файлу>
```

**Пример:**

```bash
./onegin_sort Onegin.txt
```

>При отсутствии пути к файлу используется путь по умолчанию - Onegin.txt.

Результат работы сохраняется в файл `SortedText.txt` в текущей директории.

> ⚠️ Программа ожидает максимум один аргумент командной строки — путь к файлу. При большем количестве аргументов программа аварийно завершится.

---

## 📄 Формат вывода

Файл `SortedText.txt` содержит три блока, разделённые строкой из звёздочек:

```
<строки, отсортированные лексикографически>

************************************


<строки, отсортированные как в рифмовщике (с конца)>

************************************


<исходный текст без изменений>
```

## 🧠 Реализованные алгоритмы

### QuickSort (`QSort` + `Partition`)

- Опорный элемент — средний по индексу (`pivotIndex = (n - 1) / 2`).
- Два указателя `lIndex` / `rIndex` движутся навстречу.
- Обмен элементов выполняется через `ByteSwap` — побайтово, что делает сортировку универсальной для любого типа данных.
- После обмена `pivotIndex` пересчитывается, чтобы указывать на тот же элемент после перестановки.

### Компараторы

| Компаратор          | Направление       | Особенности                                                                  |
|---------------------|-------------------|------------------------------------------------------------------------------|
| `CompareDirect`     | слева направо     | пропускает не-буквы, сравнивает через `tolower` (регистронезависимо)         |
| `CompareReverse`    | справа налево     | идёт от `strlen - 1` к началу, тоже игнорирует не-буквы и регистр            |

---

## ⚠️ Ограничения

- **Только латиница.** Программа поддерживает только латинские буквы, кодировка должна быть ASCII.
- Вывод оригинального текст предполагает, что изменялся лишь порядок указателей на исходные строки, а не содержимое строк.
